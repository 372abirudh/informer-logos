# Informer resource pack

Public resources the Informer Android app downloads in the background (about once a day, only when online):

- `png/<key>.png` — 128 x 128 brand logos (extra to the ones built into the app).
- `manifest.json` — every brand Informer knows and the words used to match it.
- `data/merchants.json` — merchant directory: name, category, match words, website, Android app.
- `data/senders.json` — SMS sender codes (e.g. HDFCBK) with organisation and type.
- `resources.json` — signed index: version plus every file with its size and SHA-256.
- `resources.json.sig` — ECDSA P-256 / SHA-256 signature of `resources.json`.

The app only accepts files listed in a correctly signed index whose SHA-256 matches, so altered
files are rejected. Everyone downloads the same files, and no user data is ever sent.

Generated by `tools/fetch-logos.js` and `tools/publish-resources.js` in the Informer app
repository. Logos are trademarks of their owners, used only to identify them.
