# Informer logo pack

Brand logos that the Informer Android app downloads in the background after install,
so banks, stores and services show their logo instead of initials.

- `manifest.json` — every brand Informer knows: key, name, the words used to match it
  in SMS / notifications, and whether it ships inside the app (`core`) or comes from
  this pack (`extra`).
- `png/<key>.png` — 128 × 128 logos for the `extra` brands.

The app fetches the whole pack (the same files for everyone), so downloading it never
reveals which banks or shops a user deals with. No user data is ever sent.

Generated by `tools/fetch-logos.js` in the Informer app repository and published here
unchanged. Logos are trademarks of their respective owners and are used only to
identify them.
